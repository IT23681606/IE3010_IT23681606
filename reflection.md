# Structured Reflection – IE3010 NetMessenger

## 1. What I Learned
I learned how a TCP client-server application is organised in C and how a client connects to a server using an IP address and port number. I also learned to compile programs using a Makefile and manage project versions with Git and GitHub.

## 2. Challenges Faced
Challenges included configuring the development environment, compiling the server and client, checking connection failures, and testing application commands. Compiler warnings also showed the importance of reviewing string formatting and unused parameters.

## 3. How I Addressed the Challenges
I checked the server status, verified the configured port, rebuilt the programs, tested client connections, and examined command responses. I also checked the project files, storage directory, and Git history.

## 4. Testing and Results
The client successfully connected to the server on TCP port 7606. Registration of user1 succeeded, and the LIST command displayed five users during the multi-client test. A test file containing "Hello NetMessenger" was present in the required storage directory.

## 5. Improvements
Further improvements could include resolving compiler warnings, strengthening input validation, improving error handling, and expanding tests for invalid commands and file transfers.

## 6. Conclusion
This assignment helped me practise C programming, TCP networking, Linux development tools, testing, and version control. I also learned the importance of maintaining clear documentation and genuine test evidence.
